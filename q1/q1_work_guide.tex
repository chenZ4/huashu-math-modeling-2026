\textbf{共享核心 + 每问客制层}：B*-Tree 拓扑、Skyline 解码、SA 引擎、解析器、测试 oracle
是 Q1/Q2/Q3 共用的"已验证机械资产"，只维护一套、单套测试回归（避免复制陷阱）。每问的

（参考 skyline 解码器、独立 HPWL、暴力枚举最优、定义校验器），并辅以 ASan/UBSan 双轨。

\section{Phase 1：B*-Tree 核心 floor\_plan.hpp}
% ============================================================

\subsection{功能概述}
\label{sec:fp}

封装 B*-Tree 表示、三种扰动算子（旋转 / 删除-插入 / 节点交换）、Skyline 轮廓解码、
竞赛格式解析器（.blocks/.nets/.pl）。

\subsection{关键结构}

\begin{itemize}
    \item \texttt{NODE}：10-bit 位压缩的父子/左右子指针 + 旋转位（内存池，支持至 1023 节点）。
    \item \texttt{TREE}：拓扑操作（\texttt{del\_from\_tree} / \texttt{ins\_to\_tree} /
          \texttt{swap\_two\_nodes} / \texttt{swap\_near} / \texttt{swap\_not\_near}），
          均通过 \texttt{ValidateTree()} 白盒校验（DFS 计数 == N、无环、父子双向绑定）。
    \item \texttt{init()}：DFS 前序放置，\texttt{find\_max\_y} 维护 y 轮廓
          （\texttt{std::list} + 迭代器前插语义），天然无重叠。
    \item \texttt{cost()}：返回 (HPWL, W, H)；HPWL 按引脚几何中心（块：$2x+w$，终端：$2x$）。
    \item 构造器 \texttt{free\_outline} 参数：Q1 模式跳过"超轮廓强制旋转"（自由轮廓无此概念）。
\end{itemize}

\subsection{输入格式}

\begin{lstlisting}
.blocks:  NumHardBlocks : 100 / NumTerminals : 334 / b0 block 4 (0,0) (0,33) (43,33) (43,0)
.nets:    NumNets : 885 / NetDegree : 2 / p1 / b26
.pl:      p1 0 0
\end{lstlisting}

\section{Phase 2：快速模拟退火引擎 sa.hpp}
% ============================================================

\subsection{Mode 参数化}

\begin{lstlisting}[language=C++]
enum class Mode { Q1, Q2 };   // Q1: 自由轮廓面积+长宽比；Q2: 固定轮廓+HPWL
\end{lstlisting}

Q1 模式（本问）：
\begin{itemize}
    \item \texttt{feas()} 恒真（无轮廓约束）。
    \item \texttt{q1\_cost}：加权代价（见 \ref{sec:cost}），固定权重，无自适应 $\beta$ 压力机制。
    \item 单阶段：仅 \texttt{run2}（精修退火），不做 Q2 的"先找可行"阶段。
    \item 初始温度加热：\texttt{\_init\_T2 = \_init\_T / 20}（Q2 为 /50），提升探索性。
\end{itemize}

\subsection{代价函数}
\label{sec:cost}

\begin{equation}
f = \lambda \cdot \frac{W \cdot H}{\overline{A}}
    + (1-\lambda) \cdot \frac{r + 1/r - 2}{\overline{P}},
\qquad r = \frac{\max(W,H)}{\min(W,H)}
\end{equation}

\begin{itemize}
    \item 长宽比惩罚采用对称形式 $r + 1/r - 2$：旋转整个芯片等效于长宽比取倒数，
          对称惩罚保证两者代价相同。
    \item $\lambda = 0.5$：面积与长宽比归一化后均衡（经扫描 $\lambda \in [0.45, 0.95]$ 确定）。
    \item $\overline{A}, \overline{P}$：构造期采样 $N+1$ 个随机布局的归一化均值。
\end{itemize}

\subsection{收敛 log 与过程快照}

\begin{itemize}
    \item 每温度层写一行：\texttt{phase iter T best\_cost alpha feas}。
    \item 每个 \texttt{run2} 结束后按温度层数 9 等分输出 9 个 checkpoint 布局：
          \texttt{snap k iter W H} 头 + N 行 \texttt{name x1 y1 x2 y2}。
    \item 画图程序与求解完全解耦：求解只写文件，可视化后处理读取 log 出图。
\end{itemize}

\subsection{oracle 体系}

\begin{itemize}
    \item \textbf{O1 定义校验}：从 B*-Tree 定义出发验证 x 关系 + 原点 + 无重叠 + 尺寸保持。
    \item \textbf{O2 差分解码}：独立参考解码器（数组 skyline + 严格相交语义，与实现完全
          不同算法），随机树/全部形状逐块全等；穷举 N=6/7/8 全部二叉树形状
          （Catalan 132/429/1430）× 多组标签/旋转。
    \item \textbf{O3 cost oracle}：独立 HPWL（无预处理/无排序）与 \texttt{cost()} 全等；
          手算用例（含旋转后中心映射）。
    \item \textbf{O4 算子语义}：交换 = 位置互换且节点集合并集守恒；删除-插入子树不丢失。
    \item \textbf{O5 SA}：固定种子可复现、best 历史单调（分段）、与暴力枚举最优对照。
    \item \textbf{D 系列}：内存安全（N=1 除零守卫、1023 节点压测、Crusher 500 模块）、
          Skyline 极限、SA 数值（NaN 防护）、解析器三格式。
\end{itemize}

\section{关键设计决策}
% ============================================================

\subsection{为什么共享核心而不是每问复制？}

B*-Tree/解码/SA 是 Q1-Q3 共用的机械正确性资产（已由 1027 断言证明）；复制会造成
4 份代码 4 倍测试与 4 倍修 bug 成本（复制陷阱）。模型差异（代价/约束/阶段）通过
\texttt{Mode} 参数化 + 每问客制层表达。Q4（L/T 模块）是不同模型，独立开发但复用
测试方法论。

\subsection{为什么 $\lambda = 0.5$？}

扫描 $\lambda \in [0.45, 0.95]$ 得到权衡曲线：$\lambda=0.8$ 时 SA 卡在长条局部最优
（n300 长宽比 4.4）；$\lambda=0.5$ 时 n100 达到长宽比 1.002、面积利用率 0.942。
0.5 是面积与长宽比的均衡点（归一化后两项同量级）。

\subsection{为什么初始温度 /50 加热到 /20？}

HW2 原版 /50 对 Q1（无可行性压力）太冷，搜索易陷局部最优；加热后 n100 长宽比
从 1.9 降到 1.0，且面积利用率反而提升。

\subsection{为什么多轮取优？}

SA 是随机启发式，单次运行结果波动（n300 长宽比 1.5~4.4）；5 轮取
\texttt{(area, aspect)} 字典序最优可将波动压到可接受范围。

\subsection{为什么差分测试而不只靠单元测试？}

白盒测试的期望值若来自实现推导会"被代码绑架"（本项目曾两次手推错误）。独立参考
解码器 + 穷举形状覆盖，从语义定义出发验证，才是真正的正确性证据。

\begin{enumerate}
    \item \textbf{图没更新}：求解只写 output/，画图每次新建时间戳目录——直接看最新目录。

\end{enumerate}
