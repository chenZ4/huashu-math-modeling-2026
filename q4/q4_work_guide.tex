\section{问题 1 模型回顾与问题 4 模型修正讨论}
% ============================================================

\subsection{问题 1 模型基线}

\begin{itemize}
    \item \textbf{表示}：B*-Tree 二叉树（节点 = 矩形模块；左子 = 父右邻、
          右子 = 父上方），任意合法布局可编码（完备性）。
    \item \textbf{解码}：DFS 前序 + 水平轮廓线定位，$y$ = 与 $x$ 区间相交的
          最高支撑顶，天然无重叠。
    \item \textbf{目标}：芯片轮廓面积最小（长宽比次目标）；约束：无重叠、
          模块 90° 旋转。
    \item \textbf{搜索}：模拟退火（三种扰动算子：旋转 / 删除-插入 / 交换）。
\end{itemize}

\subsection{问题 4 的两处变化}

\begin{enumerate}
    \item 模块不再全是矩形：出现 \textbf{L 型、T 型} 模块。
    \item 旋转扩展：所有模块可进行 \textbf{90°/180°/270°} 旋转。
\end{enumerate}

\subsection{模型修正（四条）}

\textbf{修正一：模块表示 --- 矩形分解}

L/T 型模块可表示为\textbf{固定相对位置的矩形并集}：

\begin{equation}
M = \bigcup_{i=1}^{k} R_i, \qquad
R_i = \{(x_i, y_i, w_i, h_i)\} \text{ 相对坐标固定}
\end{equation}

例如图 3 的 T 型（b1）：顶横条 $4\times2$ 与居中竖干 $2\times2$
（bbox $4\times4$，面积 12）；L 型（b2）：左竖条 $1\times4$ 与右下横条
$1\times2$（bbox $2\times4$，面积 6）。

\textbf{修正二：节点语义 --- 矩形升级为超块}

B*-Tree 节点从"单个矩形"升级为"\textbf{超块}"（矩形组，内部相对位置固定、
整体移动与旋转）。树的父子/左右子关系语义\textbf{不变}。

\textbf{修正三：解码 --- 凹角精确支撑}

超块放置时，其 $y$ 坐标由内部各矩形分别对轮廓求支撑，取最大值：

\begin{equation}
y_{\text{block}} = \max_{i} \left( \text{support}(R_i) - y_i \right)
\end{equation}

其中 $\text{support}(R_i)$ 为 $R_i$ 的 $x$ 区间与已放置矩形相交的最高顶。
该式使 \textbf{L/T 凹角空间被充分利用}（对比"按 bbox 放置"浪费凹角），
是无重叠前提下更紧凑的解码。

\textbf{修正四：旋转 --- 四向}

0°/90°/180°/270° = 分解矩形组的整体旋转：对组内所有矩形做角点变换
$(x,y)\mapsto(-y,x)$ 并归一化平移，\textbf{预计算 4 组坐标}供枚举。

\subsection{目标与约束保持不变}

目标（包围盒面积最小）与约束（无重叠）与问题 1 完全一致——这是
"模型修正而非重新建模"的关键论证：修正仅发生在\textbf{表示粒度}与
\textbf{解码支撑}，目标函数与搜索框架未变。

\subsection{算法修正与延续性}

\begin{itemize}
    \item 搜索框架不变：仍为 B*-Tree 拓扑空间上的搜索。
    \item \textbf{4 模块实例}：拓扑空间极小（树形 Catalan(4)=14 $\times$
          标签排列 $4!$ $\times$ 旋转 $4^4$ $=$ 86\,016 组合），
          直接\textbf{穷举}，配合面积下界可\textbf{证明全局最优}。
    \item \textbf{大规模实例}：沿用问题 1 的模拟退火流程，仅将解码替换为
          超块版本——满足题目"在问题 1 算法基础上适当修改，不要求重新设计
          新的优化算法"。
\end{itemize}

\section{Phase：q4\_solver.py}

\subsection{模块定义}

\begin{lstlisting}[language=Python]
MODULES = {
    "b1": [(0, 2, 4, 2), (1, 0, 2, 2)],   # T 型：顶横条 4x2 + 竖干 2x2，面积 12
    "b2": [(0, 0, 1, 4), (1, 0, 1, 2)],   # L 型：左竖条 1x4 + 右下横条 1x2，面积 6
    "b3": [(0, 0, 2, 1)],                 # 矩形 2x1，面积 2
    "b4": [(0, 0, 1, 4)],                 # 矩形 1x4，面积 4
}
TOTAL_AREA = 24
\end{lstlisting}

\subsection{关键实现}

\begin{itemize}
    \item \texttt{rotate\_90}：角点变换 + 归一化平移，四向预计算。
    \item \texttt{gen\_shapes}：递归生成全部二叉树形状（相对索引组合）。
    \item \texttt{place}：超块解码（x 树关系 + y 凹角精确支撑）+ 矩形级重叠检查。
    \item \texttt{brute\_bbox\_version}：按超块 bbox 放置（必合法对照版）。
    \item 剪枝与断言：$best\_area \ge TOTAL\_AREA$（下界）、
          $best\_area \le bbox\_version$（精确版不劣于 bbox 版）。
\end{itemize}

\section{最优性证明}
% ============================================================

\textbf{命题}：最小包围盒面积为 24，且为全局最优。

\textbf{证明}：
\begin{enumerate}
    \item \textbf{下界}：任意合法布局的包围盒面积 $\ge$ 模块总面积 $= 24$
          （4 模块互不重叠）。
    \item \textbf{可达性}：强算穷举 86\,016 种组合，找到面积 $=24$ 的合法布局
          （无重叠，矩形级验证）。
    \item 由 1、2：$24 \le$ 最小面积 $\le 24$，故最小面积 $=24$，
          \textbf{全局最优}（下界可达性证明）。
\end{enumerate}

该证明不依赖搜索运气：穷举覆盖全部 B*-Tree 拓扑（完备性），
任何更优布局（面积 $<24$）将违反下界，故不存在。
